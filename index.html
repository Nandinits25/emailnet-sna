Global Density 0.1923

Network Density

Network density measures the ratio of actual directed communication channels to the maximum possible number of directed connections between all 89 individuals:

$$D = \frac{|E|}{|V|(|V| - 1)} = \frac{1,506}{89 \times 88} \approx 0.1923 \text{ (19.23\%)}$$

Approximately 1 in every 5 potential directed communication channels exists in Department 3.

Clustering / Triads 0.3688

Network Transitivity

Transitivity measures the tendency of connected nodes to form closed triangles (triadic closure). It quantifies the fraction of all two-step paths that are closed by a directed edge:

$$T = 3 \times \frac{\#\text{ Triangles}}{\#\text{ Triads}} = 0.3688 \text{ (36.88\%)}$$

A transitivity of 36.88% confirms substantial localized clustering into collaborative research sub-teams.

Bilateral Ties 0.7078

Network Reciprocity

Network reciprocity measures the extent to which directed connections are mutual across communication partners ($A \rightarrow B$ and $B \rightarrow A$):

$$r = \frac{|E \cap E^T|}{|E|} = \frac{1,066}{1,506} \approx 0.7078 \text{ (70.78\%)}$$

Out of 1,506 directed ties, 1,066 edges belong to mutual reciprocal pairs (533 bidirectional pairs).

Degree Correlation -0.1387

Degree Assortativity

Degree assortativity evaluates the correlation between degrees of connected nodes across directed communication channels:

$$r_{\text{deg}} = \text{Corr}(k_{\text{source}}^{\text{out}}, k_{\text{target}}^{\text{in}}) = -0.1387$$

The negative value indicates mild degree disassortativity: a tendency for nodes with different connectivity levels to be connected. (It is neither good nor bad; it reflects functional cross-tier connectivity).

College Social Network Analysis • Activity 1 (10 Marks)

Email Communication Network Analysis and Identification of Structurally Central Individuals

Social Network Analysis (SNA) Activity 1 • Dataset: Email-Eu-Core Temporal Department 3 (Stanford SNAP)

1. Activity 1: Network Visualization and Analysis

Investigate the structural topology of an organizational email communication network (Department 3), identify structurally central individuals using multiple centrality measures, assess network clustering, reciprocity, and degree mixing patterns.

2. Objective

To construct a directed network of email exchanges among Department 3 researchers, compute exact node-level centralities (degree, closeness, betweenness) and macro-level network properties (transitivity, reciprocity, assortativity), and explain the communication hierarchy and information diffusion dynamics.

3. Tools & Dataset

  • Python: Core computational language for parsing and graph orchestration.
  • NetworkX: Graph analytics framework for directed network construction, pathfinding, and centrality calculations.
  • Pandas: High-performance data manipulation for tabular email logs.
  • Matplotlib: Static publication-grade visualization engine.
  • Interactive Graph Library (Cytoscape.js): Dynamic force-directed graph rendering with zoom, pan, drag, and node inspection.
  • Email-Eu-Core Temporal Department 3: Verified empirical dataset with 89 unique nodes, 1,506 directed edges, and 12,216 records.
  • Stanford SNAP: Stanford Large Network Dataset Collection source of truth.

4. Methodology

Dataset (12,216 records) → Preprocessing → Directed Network Construction (89 nodes, 1,506 edges) → Network Visualization → Degree Centrality → Closeness Centrality → Betweenness Centrality → Transitivity → Reciprocity → Assortativity → Interpretation

Conclusion

The social network analysis of Department 3's email communications reveals a dense, cohesive, and highly reciprocal (70.78%) organizational network comprising 89 individuals and 1,506 directed ties. Centrality analysis definitively identifies Nodes 49, 25, and 60 as the structural anchors of the department, fulfilling complementary roles as the primary volume communicator, the most efficient receiver, and the essential boundary broker, respectively. A transitivity of 0.3688 confirms strong local team clustering, while the negative degree assortativity (-0.1387) reflects an accessible hierarchical structure where central leaders actively communicate across connectivity strata to coordinate departmental operations.
